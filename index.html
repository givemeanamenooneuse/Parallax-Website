視差滾動效果

作者：Vineet Kumar

什麼是視差滾動？

視差滾動是一種網頁設計技術，讓網站背景以比前景更慢的速度移動。當訪客向下捲動時，會產生 3D 效果，增添景深並帶來更沉浸的瀏覽體驗。視差的原理來自視覺錯覺：人眼會把近處物體看得比遠處 更大，因此我們會覺得遠處的物體移動得更慢。這種錯覺長期被應用在不同媒介中，營造更真實的效果。 視差最早出現在傳統動畫中，例如迪士尼《白雪公主與七個小矮人》，以及《超級瑪利歐》等電玩。 隨著 CSS 與 HTML 的進步，視差效果才逐步演變為如今的網頁設計技術。

瀏覽器中最早的視差滾動實作之一，是由網頁開發者 Glutnix 在 2007 年以部落格文章分享，內容包含 JavaScript 與 CSS 2 的範例與示範，支援當時的 Internet Explorer 6 等瀏覽器。然而直到 2011 年 HTML5 與 CSS3 推出後，這項技術才真正受到網頁設計師的青睞。支持者認為，這是擁抱網頁流動性的一種 簡單方式，視差背景也能更好地吸引使用者並提升網站整體體驗。不過普渡大學於 2013 年的研究指出： 「……雖然視差滾動改善了使用者體驗的某些面向，但未必能提升整體使用體驗。」


為什麼要使用視差圖像？

    設計師嘗試視差圖像的主要原因有兩個：

  • 有助於講故事

    視差圖像非常適合用來說故事。優秀的設計重點在於溝通——當我們設計網站時，希望能與訪客互動， 並講述關於產品、服務或品牌的精彩故事。視差滾動能讓訪客沉浸在獨特的線上體驗中， 甚至可以打造單頁網站，讓訪客不必切換多個頁面就能讀完完整的品牌故事。

  • 有助於提升使用者參與度

    視差圖像能提升使用者參與度。降低網站跳出率是網頁設計必須關注的目標之一。跳出率指的是訪客只看一個 頁面就按「返回」或關閉分頁的比例。高跳出率會影響搜尋排名，因此任何能降低跳出率的做法都值得嘗試。 精心打造的視差頁面能提供更具動態感的體驗，讓使用者更願意停留在頁面上。


如果你想在網站中加入視差滾動效果，請考慮以下建議。

  • 有選擇地使用

    相較於在所有頁面隨時使用，視差滾動在特定元素上更能發揮效果。你可以將它用在標題或首頁， 讓視差效果強化網站設計，而不是分散使用者注意力。

  • 圖片壓縮

    視差滾動會使用多種媒體檔案與 CSS 形狀來營造景深，你不希望因為圖片過大而拖慢載入速度， 影響網站效能與使用體驗。

  • 善用色彩

    視差滾動不只關乎前景與背景的圖像，色彩也是關鍵。你可以在背景使用較低飽和度的色調， 在前景使用更鮮明的色彩，以營造更強烈的深度感。
